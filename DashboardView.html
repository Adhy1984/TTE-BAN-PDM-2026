📘 Panduan Singkat Penggunaan
1
Buat Surat Baru
Operator mengisi formulir surat resmi: nomor, perihal, kepada, isi surat, dan memilih pejabat penandatangan.
2
Pejabat Mengesahkan
Pejabat membuka halaman Persetujuan, meninjau isi surat, lalu memasukkan PIN TTE untuk mengesahkan secara elektronik.
3
PDF Ber-QR Code Terbit
Sistem otomatis membuat PDF resmi lengkap dengan QR Code TTE tersisip di antara jabatan dan nama pejabat. PDF disimpan di Google Drive.
4
Verifikasi Publik
Penerima surat cukup scan QR Code menggunakan kamera HP. Halaman verifikasi resmi langsung terbuka tanpa perlu login akun apapun.
